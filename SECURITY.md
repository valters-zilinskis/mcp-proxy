# Security Policy

This project is provided **as-is, with no security support or maintenance commitment**.

- No security fixes are guaranteed to be provided for any version.
- Issues and pull requests are welcome but may not be actioned.
- There is no SLA for vulnerability reports.

## Reporting

If you find a security issue, you are welcome to open a public issue or a private contact, but please understand **no response or fix is guaranteed**.

## Use at your own risk

This software implements a minimal OAuth compatibility shim and bearer-token proxy. It is not hardened for all threat models. Review the code yourself before deploying publicly, and follow the deployment hardening checklist in the `README.md`.
